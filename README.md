# Atari-Game
Bil 211 Summer Term Final Project-(Only Linux)

## 🕹️ Retro Atari Game Suite

A retro-style Atari game project featuring multi-threaded game mechanics, built with Java.

## 🚀 Features

* **Multi-Game Mechanics:** Includes dynamic game loops and interactive retro mechanics.
* **OOP Architecture:** Designed with object-oriented programming principles, generic utility classes, and custom event handlers.
* **Graphical Interface:** A classic retro-inspired graphical user interface (GUI).

## 🛠️ Technologies
* **Language:** Java
* **Libraries / Frameworks:** Java Swing / AWT, Multithreading

---
*Note: This project was developed as an object-oriented graphical application for computer engineering coursework.*
